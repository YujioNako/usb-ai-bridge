# 升级和备份

## Windows

下载新的完整 ZIP，解压到一个新目录。退出旧客户端，把自己的 device.json 复制到新目录，再启动新客户端。旧工作目录自行保留，不要把工作文件误当程序文件删除。

如果使用加密的 device.sealed.json，复制后运行 Unlock-Device.cmd，输入你自己设置的解锁密码。

## Pi

`pi/install.py` 用于首次安装；检测到已有完整部署会拒绝覆盖。发布的原有 Pi 端功能已在作者设备运行，但新的跨版本在线更新器尚未提供。不要为通过安装检查而删除凭据。

先通过 SSH 备份 `/opt/usb-ai-bridge`、`/etc/usb-ai-bridge`、`/var/lib/usb-ai-bridge`；使用套餐登录时还需备份 `/opt/usb-ai-codex`、`/etc/usb-ai-codex`、`/var/lib/usb-ai-codex` 和相应 systemd 单元。配置、会话和账号备份都是私密文件，不要上传 GitHub。

只有阅读目标版本的迁移说明后再更换应用文件，先等待 AI 任务结束。服务更新后确认配置、历史记录、串口和账号状态正常。当前 README 不提供未经实际验证的通用覆写命令。

## 整卡备份

需要保留整套屏幕驱动、桌面配置和已安装依赖时，关闭 Pi 后，用读卡器和能读取整卡镜像的工具制作离线整卡备份。保存到另一块磁盘，并记录校验值；最好用备用卡做一次恢复验收。

应用备份不能替代整卡镜像。GitHub 源码和 Release 都不包含你的系统镜像或任何个人登录信息。
